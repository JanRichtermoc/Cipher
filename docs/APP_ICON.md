# Cipher App Icon

A 1024×1024 teal lock-shield icon is in `Cipher/Assets.xcassets/AppIcon.appiconset/` (light / dark / tinted slots).

## Liquid Glass layered icon (optional polish)

Apple’s **Icon Composer** (free from [Apple Design Resources](https://developer.apple.com/design/resources/)) builds true Liquid Glass multi-layer icons.

1. Download **Icon Composer**.
2. Import separate layers: background gradient, shield shape, lock glyph (keep shapes simple and filled).
3. Preview light, dark, clear, and tinted appearances.
4. Export / drop the `.icon` package into the Xcode target (Xcode 26+).

Until then, the single-layer PNG set ships with the app.
